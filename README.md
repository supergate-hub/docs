# Supergate Docs

Documentation for Supergate Cloud, Token Factory, and Bio Pipeline, built with
[Fumadocs](https://fumadocs.dev) and Next.js.

## Development

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000/docs.

Docs pages live in `content/docs/`. See [AGENTS.md](AGENTS.md) for the project
layout, content rules, and commands to run before committing.
