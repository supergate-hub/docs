<Callout type="warn" title="Draft">
  Add one page per task in this folder.
</Callout>

Each task page starts from a goal, compares the tools that can reach it, and then recommends one for common situations.

Use this structure for every task page:

1. A comparison table of the candidate tools, with inputs, outputs, and capabilities.
2. Recommendations by situation.
3. Links to the tool pages.
